# Currency Rate Visualization

Учебный проект по получению и визуализации данных о курсах валют Центрального банка РФ.

## Что реализовано

* получение текущих курсов 11 валют через XML API Центрального банка РФ;
* обработка данных в формате XML;
* визуализация текущих курсов валют;
* получение динамики курса доллара США за последние 12 месяцев;
* построение графика изменения курса доллара;
* защищённое подключение к API с использованием SSL-сертификатов.

## Визуализация

Программа строит два графика:

1. текущие курсы выбранных валют;
2. динамика курса доллара США за последние 12 месяцев.

Период для второго графика рассчитывается автоматически относительно текущей даты.

## Запуск

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить программу:

```bash
python main.py
```

Программа получает данные о курсах валют через XML API Центрального банка РФ, обрабатывает XML-ответ и отображает результаты в виде двух графиков.
